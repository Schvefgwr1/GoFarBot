# 🤖 GoFarBot - Система управления конференциями

[![Spring Boot](https://img.shields.io/badge/Spring%20Boot-3.3.3-brightgreen.svg)](https://spring.io/projects/spring-boot)
[![Java](https://img.shields.io/badge/Java-17-orange.svg)](https://www.oracle.com/java/)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-13-blue.svg)](https://www.postgresql.org/)
[![Docker](https://img.shields.io/badge/Docker-Compose-blue.svg)](https://www.docker.com/)
[![Telegram Bot API](https://img.shields.io/badge/Telegram%20Bot%20API-6.9.7-blue.svg)](https://core.telegram.org/bots/api)

**GoFarBot** - это комплексная система для управления конференциями и мероприятиями, объединяющая в себе мощный Telegram-бот и веб-API для администрирования. Система позволяет организовывать регистрацию участников, управлять уведомлениями, интегрироваться с Google Forms и обеспечивать эффективную коммуникацию с пользователями.

## 🌟 Основные возможности

### 🤖 Telegram Bot
- **Интерактивное меню** с кнопками и навигацией
- **Регистрация пользователей** на конференции
- **Система ссылок** для доступа к конкретным сообщениям
- **Файловая система** с поддержкой документов и изображений
- **Персонализированные уведомления**
- **Система ресурсов** с проверкой доступа по никнейму
- **Отложенные сообщения** с настраиваемой задержкой

### 🌐 Web API
- **Управление конференциями** (создание, обновление, получение)
- **Пользовательские данные** и регистрации
- **Массовая рассылка** сообщений
- **Файловый менеджер** с поддержкой MinIO
- **Система уведомлений** с расписанием
- **JWT аутентификация** и авторизация

### 📊 Аналитика и мониторинг
- **Метрики переходов** по ссылкам
- **Статистика использования** сообщений
- **Логирование действий** пользователей
- **Мониторинг состояния** системы

### 🔗 Интеграции
- **Google Sheets API** для работы с формами
- **MinIO** для облачного хранения файлов
- **PostgreSQL** для надежного хранения данных
- **Liquibase** для управления схемой БД

## 📋 API Документация (еще в разработке)

### Конференции
```http
GET    /api/conferences           # Получить все конференции
GET    /api/conferences/{id}      # Получить конференцию
POST   /api/conferences           # Создать конференцию
PUT    /api/conferences/{id}      # Обновить конференцию
```

### Пользователи
```http
GET    /api/users                 # Получить всех пользователей
GET    /api/users/conference/{id} # Получить пользователей конференции
```

### Файлы
```http
GET    /api/files                 # Получить все файлы
POST   /api/files                 # Загрузить файл
```

### Сообщения
```http
POST   /api/handle_message/all    # Отправить всем пользователям
POST   /api/handle_message/reg    # Отправить зарегистрированным
POST   /api/handle_message/list   # Отправить списку пользователей
```

### Аутентификация
```http
POST   /api/auth/signin           # Вход в систему
POST   /api/auth/signup           # Регистрация
POST   /api/auth/refresh          # Обновление токена
```

## 💾 Структура базы данных

### Основные таблицы
- **users** - Пользователи Telegram
- **conferences** - Конференции и мероприятия
- **messages** - Сообщения бота
- **files** - Файлы и медиа
- **notifications** - Уведомления
- **user_registrations** - Регистрации пользователей
- **link_metrics** - Метрики переходов
- **message_views** - Просмотры сообщений
- **resources** - Ресурсы с проверкой доступа

## 🛠️ Технологический стек
